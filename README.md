# ZAYATHON 2026 Website

Production-ready React + Vite website for **ZAYATHON 2026** — National Level College Hackathon.

## Tech Stack

- **React 19** with **Vite 6**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Framer Motion** (for modern, silky smooth animations)
- **Lucide React** (icons)

## Directory Structure

src/

## Setup & Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
